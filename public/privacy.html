Privacy Policy

Last updated: October 10, 2026 • Krims Code AI & Multi-Bot Platform

This Privacy Policy applies to the Krims Code AI multi-bot application and web platform ("the App", "we", "us", or "our"), operated by Krylo Team (71krishivpb@gmail.com). This policy explains our commitments to privacy, data minimization, and user control.

1. Information We Collect

We collect only the minimal data strictly required to deliver bot functionality:

  • Discord Identifiers: Discord User IDs, Server (Guild) IDs, and Channel IDs to manage command execution, permissions, and roles.
  • Economy & Leveling Stats: In-game KryloCoins balance, chat/voice XP levels, inventory items, and counting streaks.
  • Server AI Memory: Server-specific facts and conversational context taught to the bot or generated during chat interactions.
  • Optional Account Links: Minecraft In-Game Names (IGNs) or YouTube/Twitch usernames solely when explicitly provided by the user for rank sync or role verification.

2. Purpose of Data Processing

All collected data is processed exclusively to deliver requested bot services: calculating leveling rank cards, maintaining counting game scores, enforcing server auto-moderation, and providing AI responses.

3. Data Isolation and Protection

Every server's data is strictly isolated.

  • Conversations and facts learned in Server A are never accessible or surfaced in Server B.
  • We do not sell, rent, lease, trade, or share user data with any marketing companies, third-party advertisers, or data brokers.
  • No private server chats or user data are used to train external commercial AI models.

4. Server Owner Data Control & Deletion

Server owners retain complete sovereignty over their data:

  • Instant Wipe: Server administrators can purge their server's neural memory and facts at any time with /memory action:reset.
  • Account Removal: Individual users may request deletion of their economy or leveling stats by contacting support.
